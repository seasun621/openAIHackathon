# SWING//BEAT

1인칭 자동주행, 3D 에이밍 노트, 레이저 트레이스와 웹스윙 롱 노트를 결합한 약 1분짜리 리듬 액션 프로토타입입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://127.0.0.1:43127/`을 엽니다.

```bash
npm run build
```

## 조작

- 마우스 이동: 조준
- 왼쪽 버튼 유지/해제: 웹스윙 롱 노트
- 오른쪽 버튼 클릭: 단발 노트 사격
- 오른쪽 버튼 유지/해제: 레이저 노트 추적
- `R`: 차트 재시작
- `Esc`: 마우스 잠금 해제

## 현재 포함된 범위

- 고정된 60초 도시 코스와 자동주행
- Alex Morgan의 임시 음원 `1:36–2:36` 구간과 동기화한 140 BPM 채보
- 단발, 레이저, 웹스윙 및 동시 노트
- `PERFECT`부터 `MISS`까지의 시간 판정
- 콤보, 정확도, 점수와 결과 화면
- Web Audio 기반 실제 음악 재생과 상호작용 효과음

상세한 설계 결정과 현재 진행률은 [PROTOTYPE_PLAN.md](./PROTOTYPE_PLAN.md)를 확인하세요.
