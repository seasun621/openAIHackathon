# Swing / Blast Core

새 게임을 설계할 때 재사용할 수 있도록 기존 프로젝트에서 **웹 스윙**, **웹 3D 렌더링 원칙**, **양손 장비 입력과 폭탄 격발**만 분리한 기술 샌드박스입니다. 점수, 스테이지, 적, 아이템, 게임 모드, 전용 아트와 사운드는 포함하지 않습니다.

## 남겨 둔 핵심

### 1. 웹 스윙 물리

- Rapier 동적 강체와 고정 `60 Hz` 물리 스텝
- 카메라 전방에 있는 옥상 앵커를 화면 좌표로 평가하는 보조 조준
- 로프 길이를 넘긴 거리에는 스프링 힘, 앵커 반대 방향 속도에는 댐핑 적용
- 로프를 감을수록 방사형 견인력과 접선 가속도를 함께 증가
- 해제 순간 누적된 감기 정도에 비례해 진행 방향과 위쪽으로 속도 보존

스윙 수치와 힘 계산은 [`src/game/config.ts`](./src/game/config.ts)와 [`src/game/Game.ts`](./src/game/Game.ts)에 모여 있습니다.

### 2. 3D 렌더링 기본 원칙

- Three.js `sRGB` 출력과 ACES 필름 톤매핑
- 기기 픽셀비 상한을 두어 고해상도 화면의 과도한 렌더 비용 방지
- 절차적으로 생성한 건물을 하나의 `InstancedMesh`로 렌더링
- 건물 전체가 지오메트리와 머티리얼을 공유하고 인스턴스 행렬·색상만 변경
- 시각 건물과 Rapier 고정 콜라이더의 크기·위치를 같은 생성 데이터에서 구성
- 외부 이미지 없이 캔버스 기반 하늘과 기본 도형만 사용

최소 도시 구현은 [`src/game/City.ts`](./src/game/City.ts)에 있습니다.

### 3. 양손 장비와 폭탄 격발

- 왼쪽 장비: 좌클릭을 누르는 동안 앵커에 로프를 연결하고 감기
- 오른쪽 장비: 우클릭으로 화면 중앙 히트스캔 발사
- 건물이 폭탄보다 가까우면 명중을 차단하는 가시선 판정
- 명중한 폭탄의 폭발 파티클, 충격 링, 반경 내 연쇄 폭발
- 제거된 폭탄은 일정 시간 뒤 다른 절차형 위치에 재생성

폭탄 선택·가시선·폭발은 [`src/game/BombSystem.ts`](./src/game/BombSystem.ts)에 분리되어 있습니다.

## 조작

- 마우스 이동: 시점
- 좌클릭 유지/해제: 스윙 연결/해제
- 우클릭: 폭탄 사격
- `WASD`: 지상 이동과 공중 방향 보정
- `Space`: 점프
- `R`: 시작 위치로 복귀
- `Esc`: 마우스 잠금 해제

## 실행

```bash
npm install
npm run dev
```

`http://127.0.0.1:43127/`에서 실행됩니다.

```bash
npm run build
```

## 파일 구조

```text
src/
  main.ts             최소 HUD와 부팅
  style.css           외부 폰트 없는 샌드박스 UI
  game/
    Game.ts           입력, 플레이어 물리, 스윙, 양손 장비
    City.ts           인스턴싱 도시, 콜라이더, 앵커
    BombSystem.ts     조준, 가시선, 폭발, 재생성
    config.ts         재사용 가능한 물리 수치
```

이 저장소는 완성된 게임이 아니라 새 게임 규칙과 비주얼을 얹기 위한 기반입니다.
